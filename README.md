# LemonCpp2
the 2rd generation of wangyizhi's LemonCpp.

常用快捷键及编译方式：

`Ctrl+C`：复制

`Ctrl+V`：粘贴

`Ctrl+A`：全选

`Ctrl+S`：保存

`Ctrl+Z`：撤销

`Ctrl+Y`：重做

`Ctrl+O`：打开文件

`Ctrl+Shift+S`：另存为

`Shift+方向键`：选中

`Ctrl+D`：删除整行

`Ctrl+E`：复制整行

`Ctrl+X`：剪切

`Ctrl+N`：新建文件

`Ctrl+W`：关闭当前文件，如果关闭完无文件了会新建。

`Ctrl+[ / Shift+Tab`：去掉选中内容/本行的一个缩进。

`Ctrl+] / Tab`：给选中内容/本行增加一个缩进。

`Select+(/{/[/"/'`：给选中内容包一层符号。

`Ctrl+Tab`：切换到下一个文件

`Ctrl+Shift+Tab`：切换到上一个文件

`Ctrl+Backspace`：删除整个单词

鼠标拖动：选中

`F9`：编译

`F10`：运行

`F11`：编译运行



编译选项在 `settings -> Edit Compile Command` 中设置，使用 `%FILE%` 代替文件名，使用 `%OUT%` 代替可执行文件名，注意在其两边加上双引号。



在 `settings -> Edit Default` 中设置缺省源路径（可以是绝对路径，可以是相对路径）。



中英文字体切换在 `settings` 选项卡中，内置了中文字体[更纱黑体、等线（粗）]和英文字体[consolas]在安装路径下。



按下 `Output` 或 `settings -> Output: [State]` 可以显示/隐藏编译信息栏。



可以在 `settings` 中设置 `Tab` 长度。
